# Light Delay — Guía de banda sonora

**Estado:** borrador de dirección musical. Define registros y principios; **no** es todavía una hoja de cues escena por escena.

**Propósito:** orientar la composición o generación de música (p. ej. Suno u otra herramienta) para que el sonido refuerce la física y el tono del corto sin explicar el mundo al espectador.

**Alcance de este documento:** registros sonoros, motivo central y un dispositivo compositivo derivado del retraso de la luz. La asignación toma a toma queda para un trabajo posterior.

---

## Principios

1. **La música no «actúa».** Acompaña el funcionamiento del sistema, la corrupción de un proceso o lo ajeno del contacto; no sustituye al diálogo ni anuncia el plot.
2. **La física genera forma.** El retraso lumínico no es solo tema: puede ser recurso de mezcla y composición (delay, eco, canon desfasado).
3. **Pocos registros, claros.** Tres texturas de entorno + un motivo humano mínimo bastan para unir el arco; no hace falta un tema por personaje.
4. **Referencias de vena, no de pastiche.** Las menciones a bandas sonoras existentes indican clima y método, no citas a copiar.

## Muerte de Zao: película y tráiler

- En main, festival y largo, el encuadre abandona la violencia antes del acto. Durante un negro sostenido se oyen un forcejeo breve y un golpe corporal seco; después cesan el forcejeo y la respiración, y el negro permanece lo suficiente para confirmar la fatalidad sin mostrarla.
- En el tráiler se reutiliza el corte previo al ataque, pero el negro es breve: no hay golpe resolutivo ni silencio mortuorio, la música mantiene el pulso y la imagen siguiente llega pronto. Deben quedar abiertos tanto el destino de Zao como el éxito de su transmisión.
- La partitura no sustituye estos hechos. En la película deja espacio al sonido diegético y al silencio; en el tráiler preserva la pregunta sin fingir una respuesta.

## Registros

### 1. Nave / ingeniería

| | |
| --- | --- |
| **Uso** | Sistemas, trayectoria, cabina de mando en régimen normal |
| **Carácter** | Electrónico ambiental, casi diegético |
| **Paleta** | Texturas sintéticas frías, drones de baja frecuencia; sonido que podría confundirse con el zumbido real de la nave |
| **Melodía** | Sin melodía protagónica |
| **Vena orientativa** | *Ad Astra* (Max Richter); *Annihilation* (Ben Salisbury / Geoff Barrow) |

Refuerza el principio narrativo de precisión técnica: la música acompaña el sistema en marcha, no dramatiza por encima de él.

### 2. Sabotaje / núcleo diplomático

| | |
| --- | --- |
| **Uso** | Corrupción del payload; descubrimiento del asesinato; tensión procedimental alrededor del núcleo |
| **Carácter** | Percusivo, irregular, disonancia contenida |
| **Paleta** | Pulsos que no calzan del todo; capas que se desfasan entre sí |
| **Evitar** | Orquesta clásica de suspenso |
| **Idea guía** | Música «corrupta» o procesal, como si el propio material estuviera comprometido |

### 3. Velari

| | |
| --- | --- |
| **Uso** | Contacto, infraestructura Velari, amenaza interestelar cuando tenga presencia sonora propia |
| **Carácter** | Deliberadamente ajeno al resto de la partitura |
| **Paleta** | Coro procesado, microtonalidad, escalas no temperadas |
| **Vena orientativa** | *Arrival* (Jóhann Jóhannsson): lo alienígena se oye antes de explicarse |

Da consecuencia sonora a que el tránsito y la infraestructura Velari no pertenecen al mismo mundo acústico que la Ardor. No fija aquí distancias u órbitas nuevas.

### 4. Motivo central (humano)

| | |
| --- | --- |
| **Uso ancla** | Mensaje final de la ingeniera (Zao) |
| **Carácter** | Humano, melódico, mínimo |
| **Instrumentación sugerida** | Un solo instrumento (violonchelo o piano) |
| **Forma** | Frase simple de pocas notas que puede sobrevivir sola |

**Función dramática:** hilo que une el resto. La misma frase reaparece apenas insinuada dentro de las texturas de nave/ingeniería y del ruido de sabotaje, de modo que al llegar el mensaje el oído ya la reconoce sin haberla oído completa antes.

## Dispositivo: retraso de la luz en la mezcla

El retraso lumínico es el motor de la trama; puede convertirse en dispositivo compositivo, no solo temático:

- **Delay / eco real** en la mezcla (una capa que llega «tarde» respecto de otra).
- **Canon** en el que una voz instrumental repite lo que otra tocó segundos antes, con desfase creciente según la distancia o el aislamiento de la escena.

Es coherente con tratar la física como generadora de forma narrativa, no como decoración.
