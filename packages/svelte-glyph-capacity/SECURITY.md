# Security Policy

## Supported versions

Until a stable release, security fixes are applied to the latest `0.x` release only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting for `saabi/svelte-glyph-capacity`, or contact the maintainer privately through
[the maintainer's GitHub profile](https://github.com/saabi).

Include the affected version, reproduction steps, impact, and any suggested mitigation. You should
receive an acknowledgement within seven days. Please allow time for a fix and coordinated release
before public disclosure.
