# Demo typefaces

Local copies of [Archivo](https://fonts.google.com/specimen/Archivo) (Omnibus-Type), used only by the demo.

- Variable font with `wdth` / `font-stretch` 75%–125%
- Narrow = 75%, normal = 100%, wide = 125%
- License: SIL Open Font License 1.1 (`OFL.txt`)

These files are demo assets and are excluded from the npm package.
